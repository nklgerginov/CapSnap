# CapSnap (NovaCap Studio)

AI-Powered Kinetic Subtitle Editor for Social Media Videos

CapSnap (NovaCap Studio) is a web application that uses Google Gemini AI to automatically transcribe video audio and generate professionally styled, animated subtitles for social media platforms.

## Features

- AI-Powered Transcription with Google Gemini
- Kinetic Subtitles with smart highlighting
- Multi-Platform Support (TikTok, Instagram, YouTube)
- Real-time Preview
- Advanced Styling Options
- Audio Waveform Analysis
- Project Management with Auto-Save

## Quick Start

### Prerequisites
- Node.js 18+
- Google Gemini API Key

### Installation
1. Clone the repository
2. Install dependencies: npm install
3. Copy .env.example to .env
4. Add your GEMINI_API_KEY to .env
5. Start dev server: npm run dev
6. Open http://localhost:3000

## Usage

1. Upload your video
2. AI automatically transcribes audio
3. Edit subtitles in timeline
4. Style with presets or custom settings
5. Add effects (filters, watermark, progress bar)
6. Export as MP4 or GIF

## Tech Stack

- React 19, TypeScript
- Vite 6, Tailwind CSS v4
- Express.js, Google GenAI SDK
- Web Audio API, Canvas API
